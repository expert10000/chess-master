# v1.4.0 — Opponent / Tournament Preparation

Import a single opponent’s PGN collection into a separate workspace. The coach derives their recurring early-move sequences as opening tendencies and uses the most frequent sequences as a transparent likely-repertoire summary. You can mark useful games as model games and complete a compact pre-game checklist.

This release intentionally does not mix opponent data into your own rating, weakness, or daily-study metrics. Opponent weaknesses need Stockfish-reviewed opponent moves; that requires a later analysis pass rather than guessing from unreviewed PGN. Once games from the event are saved against that opponent, their openings can be compared with the prepared tendencies.
