# v1.9.0 — Adaptive Training Optimizer

The Adaptive Training Optimizer converts the generated session into explicit time blocks. Due spaced-repetition review remains protected. The remaining time is allocated across recurring weakness/motif evidence, recent reviewed calculation errors, and a capped experimental-new-material reserve.

When intervention history qualifies for a boost, the relevant block names the method, average observed CPL improvement, and evidence count. This is observational personal evidence, not a causal claim. The 60-minute option gives longer sessions room to preserve all relevant blocks without displacing review.
