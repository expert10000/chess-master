# v1.13.0 — Season / Tournament Training Cycle

The Season Cycle turns a tournament into a closed coaching loop:

1. **Preparation** — create tournament goals with visible evidence keywords, such as “Prepare Sicilian”.
2. **Competition** — match saved personal games from the event and record execution quality and result.
3. **Post-event analysis** — inspect which prepared themes actually appeared on the board.
4. **Consolidation** — carry the evidence into the next focused training block.

Games are matched after the cycle begins by event/player text. If the event text is left blank, every later personal game belongs to the cycle. Goal appearance measures whether the intended opening or weakness keyword appeared in saved game metadata; it is transparent evidence, not a causal claim.
