# v1.2.1 — Opening Preparation Mode

Opening Preparation Mode creates a compact recall pack for a selected opponent-facing target. The first presets are **Black against the Sicilian** and **Black vs 1.d4**.

Each pack includes matching saved Black repertoire nodes, flags nodes with no prior recall attempt, and shows the frequency plus latest review outcome of matching opening deviations from the learner’s own games. The pack is intentionally compact (at most ten recall positions) so it can be completed shortly before a game.
