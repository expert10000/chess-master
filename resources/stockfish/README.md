# Stockfish executable

Place a native Stockfish executable in this directory with one of these names:

- Windows: `stockfish.exe`
- Linux/macOS: `stockfish`

The easiest method is:

```powershell
npm run stockfish:add -- "C:\path\to\stockfish-windows-x86-64-avx2.exe"
```

The executable is intentionally not committed to this repository. Stockfish is
licensed separately under GPLv3. See `THIRD_PARTY_NOTICES.md`.
